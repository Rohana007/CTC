## Architecture Overview (2 minutes)

### AWS Services Used

**Frontend Layer**:
- **Amazon S3**: Static website hosting for React application
- **Amazon CloudFront**: Global CDN for fast content delivery across India

**API Layer**:
- **Amazon API Gateway**: RESTful API with CORS, rate limiting, and request validation

**Compute Layer**:
- **AWS Lambda**: 5 serverless functions (Node.js 20.x, ARM64 architecture)
  - Concept Explainer Lambda
  - Code Analyzer Lambda
  - Viro Assistant Lambda (Socratic tutor)
  - Dictionary Service Lambda
  - Vision Analyzer Lambda

**AI Layer**:
- **Amazon Bedrock**: Claude 3 Sonnet and Claude 3 Haiku models
  - Sonnet for complex reasoning (Viro tutor, code analysis)
  - Haiku for quick responses (dictionary, simple explanations)

**Monitoring & Security**:
- **Amazon CloudWatch**: Logs, metrics, dashboards, and alarms
- **AWS IAM**: Least-privilege roles for Lambda functions

### Demo 2: Advanced Code Analysis (2 minutes)

**Feature**: Pedagogical code analysis with dry-run tables and complexity assessment

**Steps**:
1. Navigate to the Code Analyzer tab
2. Paste sample code (bubble sort or binary search)
3. Select **Marathi** as the language
4. Click "Analyze Code"

**Sample Code** (Binary Search):
```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**What to Highlight**:
- **Amazon Bedrock Claude 3 Sonnet** used for complex analysis
- Dry-run table showing variable states at each iteration
- Time complexity: O(log n), Space complexity: O(1)
- Best practices and edge cases identified
- Explanation provided in Marathi

**CloudWatch Metrics to Show**:
- Lambda duration: ~4-5 seconds
- Memory usage: ~512 MB
- Bedrock token count: ~1200 tokens

## AWS Bedrock Integration Deep Dive (2 minutes)

### Why Amazon Bedrock?

**1. Multilingual Excellence**:
- Claude 3 models excel at Indian languages
- Better quality than GPT-3.5 for Hindi, Tamil, Telugu, etc.
- Consistent performance across all 10 languages

**2. Cost Optimization**:
- Claude 3 Haiku: $0.25 per 1M input tokens (75% cheaper than GPT-3.5)
- Claude 3 Sonnet: $3 per 1M input tokens (comparable to GPT-4)
- Smart model selection: Haiku for simple tasks, Sonnet for complex reasoning

**3. AWS Integration**:
- Native integration with Lambda, CloudWatch, IAM
- No external API dependencies
- Stays within AWS ecosystem for security and compliance

**4. Performance**:
- Average response time: 2-3 seconds (Haiku), 3-5 seconds (Sonnet)
- 99.9% uptime with AWS SLA
- Auto-scaling with Lambda

### Bedrock Model Selection Strategy

| Feature | Model | Rationale |
|---------|-------|-----------|
| Concept Explainer | Claude 3 Haiku | Fast responses, simple explanations |
| Code Analyzer | Claude 3 Sonnet | Complex reasoning, detailed analysis |
| Viro Assistant | Claude 3 Sonnet | Nuanced conversation, emotional intelligence |
| Dictionary | Claude 3 Haiku | Quick lookups, cost-effective |
| Vision Analyzer | Claude 3 Sonnet | Multimodal capabilities |

## Cost Analysis (1 minute)

### AWS Free Tier Usage

**Current Monthly Costs** (Demo Period):
- **Lambda**: 500K invocations/month → $0 (within 1M free tier)
- **Bedrock**: 50M tokens/month → ~$15 (Haiku: $10, Sonnet: $5)
- **S3**: 2GB storage → $0 (within 5GB free tier)
- **CloudFront**: 500GB data transfer → $0 (within 1TB free tier)
- **API Gateway**: 300K requests → $0 (within 1M free tier)

**Total Monthly Cost**: ~$15 (Bedrock only)

**Cost Optimization Strategies**:
1. Response caching for dictionary and common concepts
2. Smart model selection (Haiku vs Sonnet)
3. CloudFront caching to reduce Lambda invocations
4. ARM64 Lambda architecture (20% cost savings)
